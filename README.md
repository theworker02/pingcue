# pingcue

Ping digests and cue fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/pingcue/

## Install / run

```bash
git clone https://github.com/theworker02/pingcue.git
cd pingcue
node src/cli.js
node --test
```
